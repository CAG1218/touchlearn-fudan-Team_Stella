描述你要做的触觉教材

不限于函数和机械臂。智能体先判断需求路径、给出置信度与待确认问题，确认后才生成 STL。

读取模型配置… 视觉模型状态待读取

支持图片、PDF、STL/OBJ、TXT/JSON：图片按结构参考，PDF/TXT/JSON 读取文字，场景 JSON 可直接排版。无法可靠转成触觉几何的请求会被明确拒绝，而不是硬生成一块无意义的板子。

手动指定视窗（可选）

也可以上传函数图片或 PDF：PDF 会先读文字层，扫描件则需配置视觉模型。离线模式不会从图片里猜公式。

支持 STL（二进制/ASCII）和 OBJ。上传后会先做网格体检：三角面数、包围盒、水密性、体积与悬垂比例。

拖入教材图片、工程图或三维文件 PNG / JPG / PDF / STL / OBJ / TXT / JSON，单文件 30 MB 以内

    STL 生成与合规检查始终在本机完成。配置云端模型后，理解阶段会把文字或图片发送到你选择的 API；密钥只保存在本机环境变量或 .env，不会写入产物。

    等待智能体理解

    左侧可以输入任意教材需求：函数、机械臂、二维示意图，或直接上传三维文件。智能体会先给出结构化草稿，确认后才开始建模。

    • 函数解析式 / 图片 → A5 触觉函数板
    • 机械臂 → 立体模型或浮雕板
    • 电路、流程、几何、细胞等二维示意图 → A5 触觉场景板
    • STL / OBJ → 缩放模型或轮廓浮雕

    使用说明

    1. 选输入。“任意需求”可以自由描述，也可以上传图片、PDF、STL/OBJ、TXT/JSON；函数和机械臂保留专用入口。

    2. 看草稿。智能体会把路由理由、理解结果、置信度和待确认问题摆出来；不会凭空补公式或尺寸。

    3. 选形态。机械臂和三维文件可选“立体缩小模型”或“A5 浮雕触觉板”；二维示意图统一排成 A5 触觉场景板。

    4. 生成产物。STL、预览、合规报告、中文讲解 WAV、二维码和打印说明会一起生成。大模型只负责理解与结构化，几何和合规判定由本机确定性代码完成。

    5. 扫码听讲解。二维码指向本机局域网地址，手机需与电脑在同一 Wi-Fi。首次使用请允许 Windows 防火墙放行 8765 端口。

    6. 打印。本智能体不直接控制打印机；把 STL 交给切片软件，按报告里的层高、支撑与方向建议打印。

    合规报告区分“可打印”和“完全合规”：前者只表示没有阻断打印的 FAIL；后者还要求没有工艺偏离和人工复核项。
