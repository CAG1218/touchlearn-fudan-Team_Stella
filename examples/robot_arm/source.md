# 机械臂案例来源说明

本案例是**原创示意图**，不是某台具体机械臂的产品图，也不包含实验室照片。

- 结构参考：常见的六轴串联工业机械臂（基座、三段连杆、J1–J3、J4–J6 腕部、两指夹爪）。
- 几何：连杆长度、关节半径、腕部放大板尺寸见 `diagram.json` 和 `docs/tactile_spec.md`。
- 比例：触觉板上的长度不是真实机械臂的比例，腕部为了可分辨做了放大；`audio.outro` 已明确说明"只表达关节顺序和连接关系，不表示真实尺寸和姿态"。
- 照片：仓库不提交任何实验室或厂商照片；`source.kind` 记录为 `photo`，指的是设计时参考过实物，最终交付物不依赖照片。

如果后续要换成某台具体设备，应新增一个案例目录，而不是修改本案例的语义，以免破坏已有 STL 和测试基线。
