# 触觉板规格（v0.2）

本规格是两个基准案例和智能体场景板的实际参数，也是后续修改布局时的验收基线。所有尺寸单位为毫米。

## 1. 画布

| 项目 | 值 |
|---|---|
| 图幅 | A5 竖版，148 × 210 |
| 安全边距 | 基准案例 5；智能体场景板 6 |
| 板厚 | 3.0 |
| 最大浮雕高度 | 0.8 |
| 最高点（含底板） | 3.8 |
| 左上定向缺口 | 5 × 5 |
| 四角倒角 | 2（缺口所在角除外） |
| 二维码预留区 | 右下 30 × 30；检查范围 113–143 × 175–205，虚线边框内缩到 114–142 × 176–204 |

定向缺口在左上角，摸到缺口即可确认上方。缺口不是装饰：盲文板如果拿反，编号顺序和"从上到下"的讲解会全部错位。

## 2. 触觉元素

### 线

| 用途 | 宽度 |
|---|---|
| 最小允许线宽 | 1.0 |
| 网格线 | 1.0 |
| 对称轴虚线 | 1.2 |
| 坐标轴 | 2.0 |
| 函数曲线 | 2.5 |
| 机械臂连杆 | 9–11 |
| 腕部放大板边框 | 2.0 |
| 二维码区虚线边框 | 1.0 |

连杆用宽线条而不是细轮廓，是为了让手指能沿着"实体"滑动，而不是在两条边之间迷路。关节用实心圆，直径 6–12，和连杆重叠。

### 文字

- 字体：仓库内置 3×5 笔画字体，支持 A–Z、0–9 和常用符号；
- 字高：标签 6，标题 6，页脚 5；
- 笔画宽度：`max(1.0, 字高 / 5)`，6 mm 字高对应 1.2；
- 笔画中心距：1.2，保证相邻笔画不粘成一块；
- 文字不做填充轮廓，避免 T 形接缝和闭合字腔在 STL 里变成薄壁。

### 盲文

中文一律按 **GF 0019-2018《国家通用盲文方案》** 编码：每一方是「声母 / 韵母 / 声调」符号，按二级标调规则省写声调；词内连写，词与词之间空一方。绝不使用英文字母盲文表逐格拼写中文。结构助词“的”单独分写，后附成分（如“们”）与前词连写；读音为 de / me / ni / ta 的“的、么、你、他、她、它”按 §11 定字简写（她 ⠞⠁、它 ⠈⠞ 各两方，其余一方），但“的、么、你、他、它”后接韵母自成的音节时回到全拼。

| 项目 | 值 | 说明 |
|---|---|---|
| 点径 | 1.6 | 0.4 mm 喷嘴可稳定成型 |
| 同格点间距 | 2.6 | 格内 2×3 点位中心距 |
| 格间距 | 6.9 | 标准方距上限 6.8，加 0.1 补偿 FDM 粘连 |
| 格宽 | 4.2 | 点径 + 点距 |
| 格高 | 6.8 | 两行点距 + 点径 |
| 点高 | 0.6 / 0.8 | 平面板 0.6，3D 表面 0.8 |
| 数字 | 数号 + 数字 | GB/T 18028-2010：每个数字前都加数号 ⠼ |
| 大写 / 小写字母 | 字母号 + 字母 | 大写 ⠠，小写 ⠰，各占一方 |
| 运算符号 | 按 GB/T 18028 点表 | + ⠣、− ⠤、× ⠦、÷ ⠲、= ⠦⠤、点乘号 ⠄ 等 |

> 解码方式：每个点字方对应一个拼音音节，请按每块板随附的 `braille_map.md`（中文盲文逐字对照表）核对声母、韵母和声调。用拉丁字母盲文表去读中文会得到无意义的字母串，这不是乱码，是拿错了表。

数字和字母都带前导符号，所以一个数字标签占两方、宽 11.1 mm；这就是为什么标签位置不能按可见数字的宽度来估算。函数图的坐标轴标签用小写 `x`、`y`、`o`，小写字母号 ⠰ 与大写号 ⠠ 同样占一方，选小写是因为它是数学书写惯例，而不是为了省方。

函数板的解析式另起一行用 GB/T 18028 数学盲文写出，例如 `y=x²-2x-3` 写成 `y=x·x-2x-3`（乘方号没有可核对的公开点表，二次方改写成点乘形式），共 19 方、宽 128.4 mm，在 A5 的可用宽度内。括号、乘方号、函数名等未收录的结构不猜点形：该行盲文整行省略，并在构建报告的 `warnings` 与 `trace` 里写明原因。标题只保留汉字（如“二次函数图像”），解析式交给下面那一行，避免 `²` 这类字符把整行标题一起废掉。

## 3. 编号方案

### 六轴机械臂

| 编号 | 元素 | 中文 |
|---:|---|---|
| 1 | BASE | 基座 |
| 2 | L1 | 第一连杆 |
| 3 | L2 | 第二连杆 |
| 4 | J1 | 第一关节 |
| 5 | J2 | 第二关节 |
| 6 | J3 | 第三关节 |
| 7 | J4-J6 | 四到六轴腕部 |
| 8 | EE | 末端执行器 |

编号按语义元素顺序，不按空间顺序。音频讲解按"从底座到末端"的触摸顺序，读图时以音频为准。腕部板内三个小圆点代表 J4、J5、J6，间距 12 mm，边缘净空 6 mm；v0 不在这三个 3 mm 圆点上单独加盲文，具体顺序由音频说明。

### 二次函数

| 编号 | 元素 | 坐标 |
|---:|---|---|
| 1 | 顶点 V | (1, −4) |
| 2 | 左根 R1 | (−1, 0) |
| 3 | 右根 R2 | (3, 0) |

对称轴 `x = 1` 不加编号，用文字和盲文直接标注；坐标轴用 `x`、`y`，原点用 `o`。曲线本身不加编号，靠连续的凸起线条识别。

## 4. 通用场景板

场景板用于电路、流程图、几何、坐标系、路线、柱状图、细胞等结构示意图。

| 项目 | 值 |
|---|---|
| 内容框 | `(8, 24, 132, 142)`：左右 8 mm，顶部留给标题，底部留给页脚与二维码 |
| 标题基线 | y = 8.5 |
| 副标题基线 | y = 17.4 |
| 图块上限 | 12 |
| 每块图元上限 | 48 |
| 阅读顺序 | 按 `reading_order` 排序，自动编号 1..N |
| 标签策略 | 每块都有编号；完整标签只在 `show_label` 为真时出现 |
| 标签避让 | 所有块几何完成后统一放置，避开标题、副标题、页脚和二维码区 |
| 中文字符 | 不进入板面标签；写入 `label_zh` 和音频 |

场景板表达**位置、连接关系和阅读顺序**，不还原照片细节，也不代表真实尺寸。这个限制会写进合规报告和产物说明。

## 5. 图例卡

带编号的平面板同时生成两张 A6（105 × 148）图例：

- `legend.svg`：视觉图例，把编号映射到英文名和中文名，供教师、家长或陪同者使用；
- `legend_card.stl`：触觉图例卡，底板厚 1.2 mm、盲文点高 0.8 mm。序号用标准凸起数字，名称用 GF 0019-2018 中文盲文按词连写；长名称按音节换行，不与页脚重叠；
- `braille_map.md`：逐字对照表，按板上的实际点阵列出每个字符的类别、拼音和点序，供教师、打印店和评审核对；该表由程序根据布局生成，不手工维护。

触觉卡由独立的 A6 布局器生成，不套用 A5 检查器；网格经二进制 STL 回读确认水密。盲人读者可以先用主板上的编号定位，再在图例卡上摸到完整中文名称，不必依赖陪同者朗读 SVG。

四级标注的落点是：L1 标题在板面上缘，中文盲文；L2 编号用标准凸起数字标在图内要素旁，与图例卡编号一一对应；L4 完整名称放在 A6 触觉卡上。**L3 板边标注带没有做**：这两块 A5 的图形区已经占到板边，硬塞 2 列 × N 行盲文会压缩图形或让标签互相压叠，触觉可读性反而下降；名称信息改由 L4 卡承载，编号 → 名称的映射在 `legend_card.stl` 与 `braille_map.md` 里都能查。这是有意的取舍，不当作已完成项对外宣称。

可直接送印的视觉版白底 A6 PDF 仍在 `fabrication/print/`；触觉版直接打印 `legend_card.stl`，打印与裁切要求见 [`fabrication/README.md`](../fabrication/README.md)。

## 6. 二维码与音频

- STL 在右下角预留 30 × 30 的空白区，并用 1 mm 虚线边框标出；
- 交互式智能体的每次构建会自动生成 `qr.png` 和 `qr_card.svg`；二维码本身**不在 STL 里**，推荐打印完成后贴一枚防水贴纸，或在预留区丝网印刷；
- 3D 底座的二维码垫与之同规则：垫面是**纯平面**，不刻凸字、不压边框内浮雕。任何凸起都会让贴纸边缘翘起、扫码失败，缩放后也只剩无法辨认的碎片；
- 二维码应指向该案例的音频页面，而不是直接指向一个会过期的临时链接；
- 音频脚本在 `audio.txt`，TTS 导出后需要做三台手机播放测试；
- 试运行 TTS 音频和本地播放页在 `fabrication/audio/`，正式测试前应替换为真人录音；
- 二维码指向的页面应同时提供文字稿，方便听障读者和无法扫码的场景。

`scripts/make_qr.py` 在拿到最终 URL 后生成二维码 PNG/SVG；没有 URL 时不会伪造一个。

## 7. 切片与打印建议

以下参数是起点，不是经过实体打印验证的结论：

| 参数 | 建议 |
|---|---|
| 材料 | PLA（哑光或普通均可） |
| 喷嘴 | 0.4 |
| 层高 | 0.2 |
| 墙数 | 3 |
| 填充 | 15–20% |
| 支撑 | 不需要，所有浮雕朝上 |
| 热床 | 纹理 PEI 或干净玻璃，首层要压平 |
| 方向 | 平板朝下，浮雕朝上 |
| 速度 | 外墙降速，避免盲文点被拖拽 |

打印后检查：

1. 用指腹沿每条线滑动，不应有断点或毛刺；
2. 盲文点应圆润、无拉丝，点与点之间不粘连；
3. 板子放平，不应翘边；
4. 二维码区保持平整，贴纸不能盖住相邻浮雕；
5. 不要用砂纸打磨盲文点，会改变点径和点高。

## 8. 已知风险

- **浮雕高度与打印机**：0.8 mm 浮雕在层高 0.2 时是 4 层，边界清晰；如果打印机挤出不足，触感会偏弱。
- **盲文点径**：1.6 mm 点径在 0.4 mm 喷嘴下可打印，但小点容易被拉丝连接，需要调整回抽和温度。
- **点径与 GB/T 40142 公开摘要的偏差**：GB/T 39758 的盲文点径区间是 1.0–1.7 mm，本仓库取 1.6 mm；民政部公开解读的触摸图形点径要求“不小于 2 mm”。两者口径不同，当前没有把 1.6 mm 点径宣称为满足 GB/T 40142 的 2 mm 要求。若把图形触摸点与盲文点分开设计，应另设更大的图形点径。
- **底板翘曲**：A5 面积较大，PLA 冷却不均会翘边；建议加裙边并保证热床附着。
- **文字可读性**：3×5 笔画字体是触觉优先，不是视觉优先；视力正常的陪同者可能觉得字形粗糙，这是有意的取舍。
- **未做耐久性测试**：多次触摸、跌落、清洗后的磨损情况尚未评估。

## 9. 变更规则

改布局时必须同步更新：

1. `src/touchlearn/layout.py` 的坐标和 `trace` 说明；
2. `examples/*/diagram.json` 中受影响的语义或约束；
3. 场景板同步 `src/touchlearn/agent/scene.py` 的内容框、模板和标签策略；
4. `docs/tactile_spec.md` 的编号表、尺寸和已知偏差；
5. `tests/` 中对应的坐标、标签数量或检查项；
6. `dist/` 与 `docs/images/`，通过 `python scripts/build_examples.py` 重新生成。

只改 `dist/` 不改源码，视为无效变更。
