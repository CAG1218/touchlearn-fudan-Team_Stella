# 路线图

路线图按“证据强度”排序，而不是按功能听起来是否酷。v0.2 已经把多模态理解、通用场景和标准检查的链路跑通，接下来最缺的仍是**真实打印**和**真实用户**，不是更多演示案例。

## v0.2.0（当前）

已完成：

- 四段式智能体：理解 → 确认 → 生成 → 合规检查；
- 交互式前端与本地 HTTP API；
- 函数、机械臂、三维、通用场景四条构建链路；
- 通用场景编译器：12 块上限、48 图元上限、自动编号、标签避让、8 个离线模板；
- 图片（视觉模型可选）、PDF 文字层、TXT/JSON、STL/OBJ 的本地读取；
- 多家 OpenAI 兼容模型接入，含视觉复用、离线降级、密钥不外泄；
- 标准规则注册表、合规报告、决策轨迹、音频、二维码、下载包；
- 82 项测试、CI；
- 标准证据表（区分条款、公开摘要、工程取值）和产品蓝图。

明确未完成：

- 实体打印；
- 盲人用户测试；
- 扫描 PDF 的光栅化与逐页视觉理解；
- 汉语盲文自动转写；
- 盲文书册版式（GB/T 44725）；
- 批量教材评测。

## 下一阶段（比赛提交前，按优先级）

### P0：实体打印一块板

**为什么**：STL 水密不等于能打印。首层、浮雕高度、盲文拉丝、翘边都只能在机器上暴露。

**做什么**：

1. 用 `dist/robot-arm-6axis/model.stl` 和一个场景板分别切片，记录喷嘴、层高、温度、速度；
2. 各打印一块，拍照记录失败点；
3. 用游标卡尺量板厚、浮雕高度、盲文点径；
4. 把实测值写进 `docs/tactile_spec.md`，不要只写“建议值”。

**验收**：板厚 3.0 ± 0.2 mm，浮雕 0.8 ± 0.15 mm，盲文点无连丝，手指可连续滑过连杆和场景线条。

### P0：完成 3–5 人盲测

**为什么**：没有用户证据，“可触摸”只是设计意图。

**做什么**：按 `docs/blind_test_protocol.md` 执行；先蒙眼试运行，再正式测试；记录失败类型和原话。

**验收**：至少 3 名参与者完成核心任务；报告里同时有通过率、失败案例和局限。

### P1：音频上线

**为什么**：作业目录已经能生成二维码和本地播放页，但公网可访问的稳定页面还没有。

**做什么**：

1. 用 `audio_script.txt` 做真人录音或更高质量的 TTS；
2. 托管到一个稳定页面，页面同时提供文字稿；
3. 启动服务时设置 `--public-url`，或把二维码指向稳定的音频页；
4. 三台手机、两种扫码 App 测试。

**验收**：扫码到播放 ≤ 5 秒，外放清晰，页面无登录墙。

### P1：扫描 PDF / 图片的可靠理解

**为什么**：当前 PDF 只读文字层；扫描件需要用户导出 PNG 并配置视觉模型，链路不够顺。

**做什么**：

1. 评估是否引入 PDF 光栅化（PyMuPDF 或系统渲染器）；
2. 光栅化后逐页交给视觉模型，先生成“页面结构候选”，再让用户确认；
3. 对多页教材增加页码选择和“只处理第 N 页”；
4. 用人工标注的 20 页样张测元素召回率和误报率。

**验收**：不是“看起来像”，而是元素/关系召回率达到约定阈值，且不确定时仍然会停下来问。

### P1：场景模板扩充

按教学场景优先级增加：

1. 受力分析图（箭头、角度、合力）；
2. 几何证明图（辅助线、全等/相似标记）；
3. 表格与层级树；
4. 简单地图与路线（方向、交叉口、地标）；
5. 物理实验装置示意。

每增加一个模板，必须同时增加：

- 一个正例（能编译、无 FAIL）；
- 一个反例（超出块数/图元/标签密度时被拒绝）；
- 一条 `trace` 决策说明；
- 一条音频讲法。

### P2：更多函数类型

验证 `function_plot` 不是只为一条抛物线写死：

- 不同系数、不同定义域；
- 三角函数与周期；
- 分段函数；
- 带参数的指数/对数。

**验收**：新函数自动生成正确关键点；不需要改布局引擎；无法解析时明确拒绝。

## 中期（比赛后）

### 上游语义提取的量化验收

做一个独立的 `extract` 阶段：输入教科书照片或手绘草图，输出符合本契约的 JSON。视觉模型只负责“有哪些元素、关系是什么”，布局和几何仍走确定性编译。验收标准不是“看起来像”，而是“元素和关系与人工标注一致率达到阈值”。

### 标准条款级核对

当前 GB/T 40142 只拿到封面、目录和公开摘要。中期应通过正规渠道获取标准正文，逐条核对点径、线高、标注距离、图例规则，并把 `docs/standards/evidence.md` 中的“公开摘要级”升级或降级。没有正文就不升级措辞。

### 材料与工艺

- 对比 PLA、PETG、树脂和 swell paper 的触感与耐久；
- 测试不同浮雕高度（0.5 / 0.65 / 0.8）对识别率的影响；
- 评估双面板、可更换卡片、磁吸拼接的可行性；
- 做 50 次触摸和清洗后的磨损测试。

### 教学协作

与特教学校或盲校老师合作，把图放进真实课程单元，观察学生是否能在讲解后独立复述结构。比单次实验室测试更有价值，也更难做。

## 非目标

- 不做通用 3D 模型生成器；
- 不做照片级三维重建；
- 不做在线图库平台（至少 v1 前不做）；
- 不做需要账号和云端的核心编译；
- 不用生成式模型替代可检查的几何；
- 不承诺“任意图片一键出图”，直到上游提取有可量化验收；
- 不做汉语盲文自动转写，直到有可靠的词法与分词依据。

## 风险登记

| 风险 | 影响 | 应对 |
|---|---|---|
| 打印机精度不足，盲文粘连 | 高 | 先打小样，调温度和回抽；必要时增大点距 |
| 盲测招募延期 | 高 | 先做蒙眼试运行；如实标注未完成，不编数据 |
| 大模型编造结构 | 高 | 归一化 + 限值 + 本地校验；不确定就 `ready=false`；模型不碰毫米和 PASS/FAIL |
| 模型服务超时或涨价 | 中 | 多供应商可切换；关键词/模板离线降级；测试不调用付费接口 |
| API 密钥泄露 | 高 | 只读环境变量/`.env`；`.env` 被忽略；状态接口只返回 `has_key`；不写作业目录 |
| 音频托管链接失效 | 中 | 稳定页面 + 文字稿；二维码指向页面而非临时文件 |
| 场景模板显得像“固定案例” | 中 | 支持任意场景 JSON；现场输入未写死需求；模板只作离线兜底 |
| 评委质疑“API 套壳” | 中 | 用四种布局引擎、确定性几何、标准检查和 trace 证明工作量 |
| 触觉图被误用为教学替代品 | 低–中 | 文档明确“辅助工具”，不替代教师讲解和真实实验 |

## 完成定义

一个版本只有同时满足以下条件才算完成：

1. 四条链路端到端构建通过；
2. 测试全绿；
3. `dist/` 与源码同步；
4. 文档更新，标准措辞与证据级别一致；
5. 至少一项新增的真实世界证据（打印、盲测、教学试用或用户访谈）。

第 5 条是 v0.2 之后每个版本必须补的，不然只是在代码里打转。
