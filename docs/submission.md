# 初赛提交清单与答辩口径

本文把"仓库里已经有什么"和"提交前还需要准备什么"分开，避免把计划当成已完成的结果。具体截止时间、文件格式和平台要求**以官方通知为准**，本文不臆造日期。

## 1. 一句话与三句话

**一句话**：触见 TouchLearn 把 STEM 图变成可触摸的 3D 结构图，用编号盲文定位、用扫码音频讲解。

**三句话**：

1. 我们不让模型"描图"，而是先把图拆成元素、关系和关键点，再由确定性布局引擎生成触觉版式。
2. 同一份 JSON 同时产出 STL、预览、可打印性报告、决策轨迹和中文讲解，改一个参数，整套产物一起更新。
3. v0 已跑通六轴机械臂和二次函数两个案例，所有产物可复现，但还没有实体打印和盲人测试。

## 5. PPT 结构（10 页）

1. 封面：项目名、队名、一句话；
2. 问题：盲人学生如何读 STEM 图；现有方案的三个缺口；
3. 洞察：描图不等于理解，语义结构才是可迁移的；
4. 方案：JSON → 双引擎 → 触觉图元 → 五类产物；
5. 案例 A：机械臂，重点讲腕部放大板的取舍；
6. 案例 B：二次函数，重点讲系数驱动和关键点计算；
7. 技术：确定性、零核心依赖、可打印性门禁、决策轨迹；
8. 验证：47 项测试、两个 PASS、水密与尺寸；明确"未打印、未盲测"；
9. 价值与可行性：成本、材料、使用场景、与特教老师的协作方式；
10. 路线图与团队：下一步打印、盲测、音频上线、更多图种。

第 8 页不要把"测试通过"说成"用户验证通过"。这是两件事。

## 6. 答辩可能被问到的问题

**Q：这不就是把图片转成 3D 吗？**

A：不是。我们没有做像素描摹。输入是语义结构，曲线由系数生成，关节由运动链放置。描摹会把原图的噪声、遮挡和透视一起带进触觉图；语义重建可以保证"关节顺序"和"关键点"这些教学信息不被噪声淹没。

**Q：为什么只有两个案例？**

A：v0 的目标是把一条完整链路做扎实：契约、双引擎、几何、检查、音频、轨迹。两个案例分别代表"串联结构"和"笛卡尔坐标"两类常见 STEM 图，能暴露不同布局问题。扩到更多图需要新引擎和上游提取，这是路线图，不是已经完成的能力。

**Q：盲人能读懂吗？**

A：我们还没有做正式盲测，所以不能说"能读懂"。我们做的是把可读性变成可检查的约束：最小线宽、标签净空、盲文点径、腕部间距，并写了可执行的盲测方案。下一步是打印和测试，用数据回答。

**Q：为什么不用大模型直接生成 3D？**

A：大模型可以帮我们提取语义，但布局和几何需要确定性和可解释性。评委可以问"为什么这个标签在这里"，`trace.jsonl` 能回答；端到端生成很难给出同等程度的可追溯性。我们把模型放在上游提取，把确定性留在下游编译。

**Q：成本多少？**

A：A5 PLA 板材料成本低，具体数字取决于当地耗材价格和打印服务报价。v0 没有做批量报价，不在答辩里编一个数。可以说明"单块板的实体体积约 96–97 cm³，按 PLA 密度折算约 120 g（实心等效；15–20% 填充时实际耗材更少）"——这是从网格体积算出来的，不是报价。

**Q：二维码里是什么？**

A：当前是音频脚本，尚未托管。二维码区在 STL 里预留，二维码本身是贴纸或后印刷。我们不想在演示里放一个打不开的链接。

**Q：和 3D 打印盲文/触觉图现有工作相比呢？**

A：现有工作更多关注单张图的手工设计或通用触觉图形生成；我们的差异是把"语义契约 + 双布局引擎 + 可打印性门禁 + 决策轨迹"做成一条可复现的编译链。这个比较需要文献支撑，答辩时只讲我们实际做的，不贬低别人。

## 7. 声明口径

可以说：

- "两个案例端到端编译通过，47 项测试通过"；
- "STL 水密、体积为正、尺寸 148 × 210 × 3.8 mm"；
- "可打印性检查 PASS"；
- "同一输入可复现相同 STL"；
- "盲测方案已写好，尚未执行"。

不能说：

- "已被盲人用户验证"；
- "可以直接上课使用"；
- "支持任意 STEM 图片"；
- "已实体打印并验证"；
- "二维码音频已上线"；
- "成本低于 X 元"（没有报价）；
- "和某产品相比更好"（没有对比测试）。

## 9. 评审视角的自检

把自己当成评委，问四个问题：

1. **这是不是一个真问题？** 盲人学生读 STEM 图确实存在结构性障碍，不是伪需求。
2. **这是不是一个真方案？** 有输入契约、有布局、有几何、有检查、有产物，不是只有概念图。
3. **证据够不够？** 代码、测试、STL、报告、轨迹都在仓库里，可复现；用户证据尚未完成，如实说明。
4. **团队能不能继续做？** 路线图有时间、有优先级、有验证方式，不是空话。

四个问题里第 3 个最容易被扣分。不要用"我们相信"替代"我们测过"。
