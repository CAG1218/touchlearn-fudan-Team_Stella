# 标准证据表与合规矩阵

检索与核对日期：2026-10-25。下表只写能公开核对的结论，并明确区分“标准正文条款”“官方公开摘要”和“工程参考值”。本仓库不是标准起草单位，不能替代标准原文。

## 一、结论先行

1. **当前触觉板的主依据是 GB/T 40142-2021《触摸图形设计及图例》**。它的公开流通 PDF 只有封面和目录，条款正文未公开；仓库里的点径、线高、标注距离等数值来自民政部国家康复辅具研究中心的公开解读，属于**公开摘要级证据**，不是逐条抄录的条款。
2. **盲文点阵的尺寸依据是 GB/T 39758-2021**（等同采用 ISO 17049:2013），不是已经废止的 GB/T 15720-2008。GB/T 15720 已于 2025-11-03 废止且无替代，不得再作为现行依据引用。
3. **GB/T 44725-2024《盲文出版物版式》只适用于盲文出版物**（图书、期刊、教材等的版式）。单张 A5/A4 触觉板本身不是盲文出版物；只有输出盲文书册、说明页时才引用。
4. **《国家通用盲文方案》（GF 0019-2018）是中文盲文的正字法依据**。本仓库所有中文标签、标题、图例都直接按该方案编码（声母 + 韵母 + 声调三格，二级标调，分词连写，§11 定字简写）；标签里的数字、拉丁字母和运算符号按 GB/T 18028-2010 编码（数号、字母号、运算符号）；每块板随附 `braille_map.md` 逐方对照。
5. **《〈中华人民共和国国歌〉国家通用盲文方案》与本项目当前 STEM 触觉板无关**，仅在音乐教材内容出现时才需要。GB/T 16431-2008《中国盲文音乐符号》同样只在音乐内容中适用。
6. **GB/T 18028-2010 仍在现行状态，但已列入修订计划**（2026-03-02 复审结论为“修订”，计划号 20261379-T-314）。涉及数学/物理/化学盲文符号时引用它，并标注“修订中”。
7. 网上常见的“GB/T 41128-2021 是盲文标志标准”是错误对应。GB/T 41128-2021 实际是《跨境电子商务 出口商品信息描述规范》；盲文在标志、设备和器具上的应用标准是 **GB/T 39758-2021**。

## 三、可直接支撑设计的公开数值

### 3.1 触摸图形（GB/T 40142-2021 的公开摘要）

民政部国家康复辅具研究中心公开文章给出的设计要点：

- 点直径不小于 2 mm；
- 线高 0.1–0.15 mm；
- 箭头距离 0.5 cm；
- 标注距离 2–12 mm；
- 颜色不超过 3 种，且高对比；
- 不同表面用高度、纹理或间隙区分。

来源：[民政部国家康复辅具研究中心公开文章](https://kffj.mca.gov.cn/n852/c26013/content.html)。

**证据边界**：这些是公开解读中的数值，不是标准条款原文。仓库把点径取 1.6 mm 是为了与盲文点径统一，低于该公开摘要的“不小于 2 mm”；这一点在 `docs/tactile_spec.md` 中作为已知偏差明确标注，不能宣称“完全符合 GB/T 40142 条款”。

### 3.2 盲文点阵（GB/T 39758-2021 / ISO 17049:2013）

- 点底部直径：1.0–1.7 mm；
- 点高：0.3–0.7 mm；户外/交通场景宜大于 0.5 mm；
- 竖向点距：2.2–2.8 mm；
- 横向点距：2.0–2.8 mm；
- 方距（同一单元格内点组之间）：5.1–6.8 mm；
- 行距：10.0–15.0 mm；
- 边缘隔离区：不小于 6 mm；
- 点顶应为圆角。

本仓库的中文盲文（含数字、字母和数学符号所在的同一张板）统一取点径 1.6 mm、点高 0.6 mm、点距 2.6 mm、方距 6.9 mm；纯英文 UEB 参考实现（`touchlearn.braille`）取点径 1.5 mm、点距 2.5 mm、方距 6.5 mm，只用于英文版工具，不进入中文板。点径、点高、点距都落在上述区间；中文方距比公开参考上限 6.8 mm 多 0.1 mm，是为避免 FDM 在相邻盲符之间架桥、把字糊在一起而增加的打印补偿，报告中单列说明。

## 五、不能宣称的内容

- 不能宣称“逐条符合 GB/T 40142-2021”：正文未公开，仓库只核对了题录和公开摘要。
- 不能宣称“通过国家标准检测”：没有送检，也没有授权检测机构报告。
- 不能宣称“盲文出版物合规”：没有输出盲文书册，未套用 GB/T 44725。
- 可以宣称“中文盲文按 GF 0019-2018 的声母、韵母、声调表和二级标调规则编码”：这一条有逐方对照表与回归测试支撑。不能宣称“已经盲文专家或盲校审校/认证”：尚未送审，也未做盲人用户实测。读校流程见 [`braille-review-protocol.md`](braille-review-protocol.md)，在它执行完并填入真实记录之前，这一条保持“未验证”。
- 不能宣称“所有汉字都能编码”：拼音表只覆盖 GB2312 常用字，未收录字符会抛 `BrailleError` 而不是猜读。
- 不能宣称“GB/T 18028 数学符号全覆盖”：只实现了本表列出的运算符号；括号、乘方号、函数号没有可核对的公开点表，遇到时省略盲文行而不是猜点形。
- 不能宣称“实体打印已验证”：STL 只经过几何、水密和可打印性检查，未经过真实切片与打印。

### 5.1 GF 0019-2018 编码核对来源

- [浙江特殊教育职业学院“指趣小课堂：国家通用盲文（十六）”](https://www.zcse.edu.cn/info/1696/47121.htm)：逐条列出二级标调的省写规则与 3.1–3.2.6 例外。
- [中国盲人协会“国家通用盲文核心数据解析”](https://www.zgmx.org.cn/newsdetail/d-71200-0.html)：声母、韵母、声调的点位表与简写说明。

两条来源互相独立且内容一致；代码只实现两者都能确认的规则。

§11 定字简写已接入：的 ⠙、么 ⠍、你 ⠝、他 ⠞、她 ⠞⠁、它 ⠈⠞；§11.2 规定“的、么、你、他、它”后接韵母自成音节时不能简写，代码按该表阻断（她不在阻断名单内）。

仍未实现：`zh/ch/sh/r/z/c/s + i` 省 `i` 的简写，遇到时按全拼输出——宁可多几方，也不猜。

### 5.2 GB/T 18028-2010 数学符号核对来源

- 4.1 数号：每一个阿拉伯数字前都加数号（3456）；混排标签不适用“整行只写两个数号”的例外。
- 5.2.1 字母号：大写 (6)，小写 (56)。
- 运算符号：+ (235)、−/= (36)、× (236)、÷ (256)、= (2356)、≠ (4+2356)、≈ (26,26)、> (135)、< (246)、≥ (135+2356)、≤ (246+2356)、± (235+36)、小数点 (2)、点乘号 (3)、间隔号前后的空方按用法规则处理。
- 未在公开可核对来源里确认的符号（括号、乘方号、函数号）一律不实现，`mathsymbols` 抛 `MathSymbolError`，版面改为省略该行。

数字与运算符的具体取值见 `src/touchlearn/mathsymbols.py` 的注释和 `tests/test_mathsymbols.py` 的逐格断言。

## 六、维护规则

1. 新增标准先查 [国家标准全文公开系统](https://openstd.samr.gov.cn/) 或 [全国标准信息公共服务平台](https://std.samr.gov.cn/)，记录题录、状态、发布日期、实施日期和链接。
2. 只把能打开、能核对到标题与范围的内容写进本表；打不开的正文标注“未获取”，不用二手摘要冒充条款。
3. 标准废止或复审结论变化时，先改本表，再改代码里的规则说明和界面文案。
4. 任何“符合/通过”措辞都必须能指向本表中的一行证据；指向不了就改成“参考”“工程取值”或“未验证”。
