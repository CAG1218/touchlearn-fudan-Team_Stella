# 盲文读校复核方案

**状态：方案已就绪，尚未执行。** 本文约定怎么请盲人读者和特教老师核对板上的盲文，而不是代替他们给出"已验证"的结论。在 §10 填上真实记录之前，README 和任何提交材料都不能写"已由盲文专家/盲校审校""已通过盲人实测"。

## 1. 目的与边界

- 目的：逐方核对板面盲文的**读法**——声母、韵母、声调、定字简写、分词空方、数号与字母号、数学符号点形。
- 不替代：图好不好用、触摸顺序顺不顺、音频讲得清不清楚，那些属于 [`docs/blind_test_protocol.md`](../blind_test_protocol.md)。
- 能力边界：读校能发现编码错误，不能证明 3D 打印出来的点一定摸得清；点形问题要和打印参数一起看。

## 2. 复核人

至少 **2 名独立复核人**，两人不交换结论、各自先盲读再对照：

| 角色 | 要求 | 负责什么 |
|---|---|---|
| 盲人读者 | 以盲文为主要阅读方式，能独立读国家通用盲文 | 真实摸读，指出哪一方读不出或读成别的音 |
| 特教 / 盲校教师 | 熟悉 GF 0019-2018；能查 GB/T 18028-2010 更好 | 判定编码是否符合正字法，给修改意见 |
| 工艺人员（可选） | 打印店或实验室操作员 | 只看点形、粘连、行距，不计入读校结论 |

两人结论不一致时，回到标准原文核对，不采用"少数服从多数"。

## 3. 材料

- 每块待校板实物 1 份（A5 函数板、A5 机械臂板、A6 图例卡各 1）；
- 该板的 `braille_map.md` 打印件（评审用，读校前不给复核人）；
- GF 0019-2018 原文、GB/T 18028-2010 原文（或注明实际可获取的版本与章节）；
- 空白读校表（见 §5）、笔、录音设备（经同意后使用）；
- 本板构建报告里的 `warnings` 与 `trace`：用来确认"省略的盲文行"是不是有意为之。

## 4. 读校步骤（每块板 20–30 分钟）

1. **盲读**：复核人不看 `braille_map.md`，从左上定向缺口开始，逐方摸读，把读到的内容按顺序写下来。读不出的方写"读不出"，不猜。
2. **对照**：主持人出示 `braille_map.md`，逐项比对，差异归类：
   - **编码**：声母、韵母、声调、简写、数号或字母号错；
   - **分词**：该空一方没空、不该空却空了；
   - **缺行/多行**：整行盲文缺失、重复或位置错；
   - **点形**：点粘连、间距不足、行距过密导致摸不清。
3. **归因**：编码与分词问题回到 `src/touchlearn/cnbraille.py`、`src/touchlearn/mathsymbols.py` 和对应测试；点形问题回到点径、点距、方距与打印参数。
4. **复读**：修完后由同一复核人只复读改动处，记录"通过 / 仍不通过"。复读不覆盖首次记录。

## 6. 逐项核对清单

- [ ] 每个汉字：声母、韵母、声调与读音一致；多音字按词义读音（`目的` 读 mùdì，不简写为 ⠙）。
- [ ] §11 定字简写：的 ⠙、么 ⠍、你 ⠝、他 ⠞、她 ⠞⠁、它 ⠈⠞；"的、么、你、他、它"后接零声母音节时已回到全拼，她不在阻断名单内。
- [ ] 分词：词内连写、词间空一方；结构助词"的"分写；"们"等后附成分连写。
- [ ] 数字：每个阿拉伯数字前都有数号 ⠼，不是整行只写一次。
- [ ] 拉丁字母：大写前有 ⠠，小写前有 ⠰。
- [ ] 数学符号：+ − × ÷ = 点乘号、小数点与不等号的点形和空方规则与 GB/T 18028 一致。
- [ ] 解析式行：与打印式表达同一函数；`x²` 改写成 `x·x` 的原因已向复核人说明。
- [ ] 标题：只含汉字，没有把 `²` 之类不可编码字符带进标题行。
- [ ] 缺行：报告 `warnings` 中声明的省略行，复核人确认"确实没有这一行"且可接受。
- [ ] 图例卡：A6 卡上的名称与主板编号一一对应。

## 7. 判定线

- 编码类错误必须 **0 处**才算该板通过；
- 分词类允许 ≤ 1 处，记录后下一版修；
- "摸不清"不由读校判定通过，转交打印与触觉评估；
- 任何一块板未通过，不对外宣称该板盲文正确。

## 8. 结果怎么写

在 §10 追加：日期、复核人角色（匿名）、板号、错误清单、已修/未修、复读结果。原话照录，不写成"专家一致认为很好"。

## 9. 现在能支撑到什么程度

- `braille_map.md` 由程序按实际布局生成，逐方列出类别、读音、点序，可作为对照基准；
- `tests/test_cnbraille.py` 与 `tests/test_mathsymbols.py` 对简写、阻断、分写、数号、运算符有逐格断言，改错会挂测试；
- `docs/standards/evidence.md` §5.1、§5.2 记录了规则来源：GF 0019-2018 与 GB/T 18028-2010，经浙江特殊教育职业学院公开课和中国盲人协会解析文章双向核对；
- 这些只证明"规则层自洽且可追溯"，**不证明**真实盲人摸读无误——后者要靠本文执行后才能写。
