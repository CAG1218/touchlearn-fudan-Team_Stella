# TouchLearn 产品蓝图

## 1. 一句话

TouchLearn 是一个把**任意可结构化的 STEM 学习材料**转成可打印触觉产物的本地智能体：用户上传图片、PDF、文字或三维文件，智能体先理解并给出可修改的草稿，确认后用确定性几何内核生成 A5 触觉板或立体模型，再跑标准检查，输出 STL、预览、音频、二维码和可追溯报告。

机械臂和二次函数只是两个演示样例，不是产品边界。

## 2. 要解决的问题

视障学生拿到的教材图往往是“给眼睛看的”：电路用颜色区分导线，几何用细线画辅助线，流程图用箭头方向表达顺序，函数图依赖坐标网格。普通 3D 打印只能复制形状，不能自动回答三个问题：

1. 这张图里**哪些元素必须被摸到**？
2. 元素之间**谁连谁、谁先谁后**？
3. 生成出来的板子**能不能打印、能不能安全触摸、有没有违反触觉图形规范**？

TouchLearn 把这三个问题拆成“理解 → 确认 → 生成 → 合规检查”四段，并让每一段都有可核查的中间产物。

## 3. 目标用户与场景

| 用户 | 典型输入 | 期望输出 |
|---|---|---|
| 特教老师 | 教材照片、练习册 PDF、手绘示意图 | 可打印 A5 触觉板 + 中文讲解音频 |
| 视障学生 | 函数解析式、几何描述、路线描述 | 可独立触摸阅读的编号图 + 扫码音频 |
| 教材编辑 | 章节插图、流程图、表格 | 批量生成的结构示意图与合规报告 |
| 创客/家长 | 三维模型、机械结构照片 | 缩放立体模型或浮雕触觉板 |
| 比赛评委 | 任意新图 | 证明系统不是两个硬编码案例 |

## 4. 产品原则

### 4.1 模型只做理解，不做几何

大模型擅长分类、读图、抽取结构，不擅长保证毫米级尺寸和可打印性。因此：

- 模型输出**归一化 0–100 坐标**的场景 JSON，或函数解析式、机械臂参数；
- 本地代码负责限值、碰撞、版式、三角化、水密和标准检查；
- 模型给出的坐标不会直接变成毫米，也不会改变 PASS/FAIL。

### 4.2 不确定就停下来问

图片看不清、PDF 是扫描件、描述缺少关键连接关系时，草稿标记为“需要补充”，并给出可选项。系统不会为了出图而编造一个看似合理的结构。

### 4.3 所有产物同源

`diagram.json` / 场景 JSON 是唯一真源。STL、SVG 预览、音频脚本、二维码页面、合规报告都从同一份结构生成。改一个标签，版式和讲解一起变。

### 4.4 离线可演示

核心几何零第三方依赖，8 个场景模板和两个专用引擎在断网时可用。接入大模型是增强，不是运行前提。

## 5. 四段式智能体

```text
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│ 1. 理解       │ → │ 2. 确认       │ → │ 3. 生成       │ → │ 4. 合规检查   │
│ 多模态输入     │   │ 可编辑草稿     │   │ 确定性几何     │   │ 规则引擎      │
└──────────────┘   └──────────────┘   └──────────────┘   └──────────────┘
```

### 第一段：理解

输入可以是：

- 图片：PNG/JPG/WEBP/BMP；
- 文档：PDF（读文字层）、TXT、JSON；
- 三维：STL/OBJ；
- 文字：自然语言需求、函数解析式、机械臂描述；
- 显式结构：场景 JSON、离线模板。

本地先做文件解析：PDF 用可选 `pypdf` 读文字层，TXT/JSON 直接读，STL/OBJ 解析网格，图片保存为来源证据。随后路由：

- 有显式解析式 → 函数；
- 有显式规格 → 机械臂；
- 有 STL/OBJ → 三维；
- 有场景 JSON/模板 → 场景；
- 否则用大模型分类，失败退回关键词。

### 第二段：确认

页面展示草稿：置信度、识别到的元素、可修改字段、需要确认的问题、来源文件。用户可以改函数表达式、视窗、机械臂自由度/连杆长度/末端执行器、场景标题和图块顺序。确认前不构建。

### 第三段：生成

- 函数：表达式解析 → 采样 → 坐标轴/曲线/零点/极值 → 触觉布局；
- 机械臂：运动链 → 连杆/关节/末端 → A5 浮雕板或缩放立体模型；
- 通用场景：图块图元 → 阅读顺序编号 → 标签避让 → 触觉布局；
- 三维：网格归一化 → 缩放立体或高度场浮雕；
- 统一输出二进制 STL、SVG 预览、决策轨迹。

### 第四段：合规检查

规则引擎检查边距、线宽、标签间距/净空、二维码区、浮雕范围、网格水密、体积方向、盲文点阵、音频是否就绪。结果为 PASS / DEVIATION / NEEDS_REVIEW / FAIL，并写入 `compliance.json`、`compliance.md` 和作业清单。模型不参与判定。

## 6. 输入端到输出端

| 输入 | 路由 | 草稿 | 输出 |
|---|---|---|---|
| 函数图片 | 函数 / 视觉 | 解析式候选 + 视窗 | A5 函数触觉板 |
| `y=x^2-2x-3` | 函数 | 直接解析 | A5 函数触觉板 |
| 机械臂照片/工程图 | 机械臂 / 视觉 | 自由度、连杆、末端 | 立体模型或 A5 浮雕板 |
| 机械臂文字描述 | 机械臂 | 参数候选 | 同上 |
| STL/OBJ | 三维 | 网格健康信息 | 缩放立体或浮雕板 |
| 电路/流程图/几何/细胞/路线/柱状图 | 场景 | 场景 JSON | A5 结构触觉板 |
| 场景 JSON | 场景 | 直接归一化 | A5 结构触觉板 |
| 无法可靠结构化的散文 | 不支持 | 明确拒绝 + 建议 | 不生成无意义板子 |

## 7. 通用场景编译器的边界

当前场景引擎支持：

- 图元：线/折线/路径、多边形/三角形、矩形、圆、椭圆、箭头、圆弧、点、文字、盲文；
- 图块：最多 12 个，每块最多 48 个图元；
- 阅读顺序：自动编号 1..N，完整标签可选显示；
- 8 个离线模板：三角形与高、3-4-5 直角三角形、串联电路、流程图、平面直角坐标系、路线图、柱状图、植物细胞。

它**不**做：

- 照片级还原；
- 真实尺寸测量；
- 自动识别任意图片中的每一个像素；
- 汉语盲文自动转写；
- 盲文书册版式。

这些边界会在草稿和产物里明确写出，不用“AI 自动生成”掩盖。

## 8. 前端

单页本地应用，无框架、无构建步骤：

- 四个入口：任意需求、函数图像、机械臂、三维文件；
- 顶部显示文本模型和视觉模型状态；
- 任意需求页支持自由文字、图片/PDF/STL/OBJ/TXT/JSON 上传、8 个模板；
- 草稿卡展示路由理由、置信度、可编辑字段、问题清单；
- 构建页展示进度、STL 下载、预览、合规报告、音频、二维码；
- 所有数据留在本机 `outputs/`，密钥只在环境变量或 `.env`。

## 9. 产物清单

一次成功构建的作业目录包含：

| 文件 | 用途 |
|---|---|
| `model.stl` | 可直接切片打印 |
| `preview.svg` | 与几何同源的矢量预览 |
| `qr.png` / `qr_card.svg` | 指向音频页的二维码与贴纸卡 |
| `audio.html` / `narration.wav` / `audio_script.txt` | 扫码播放页、语音、文字稿 |
| `compliance.json` / `compliance.md` | 规则级检查结果 |
| `diagram.json` | 本次构建的语义快照 |
| `decision_trace.json` | 路由、版式、检查的决策轨迹 |
| `manifest.json` | 标题、模式、几何指标、文件哈希 |
| `README.txt` | 给打印者的说明 |

## 10. 与打印的关系

TouchLearn 不负责实体打印，也不假设用户拥有某台打印机。用户拿 `model.stl` 去自己的切片软件和打印机。连接打印机、自动下发打印是可选扩展，不是主链路；当前版本不实现，也不拿“已连接打印机”做演示承诺。

## 11. 演示脚本（建议 5 分钟）

1. **任意需求**：输入“画一个串联电路，电池、开关、电阻和灯泡依次连接”，展示路由理由、5 个图块、阅读顺序、可编辑标题。
2. **确认**：改标题，点击生成；展示 STL 预览、合规计数、二维码与音频脚本。
3. **函数**：输入 `x^2-2x-3`，展示零点/顶点/对称轴识别与 A5 板。
4. **机械臂**：用文字描述六轴机械臂，选择立体或浮雕，展示两种输出模式。
5. **边界**：输入“帮我写一篇作文”，展示明确拒绝，说明系统不会编造结构。
6. **标准**：打开 `docs/standards/evidence.md`，说明哪些是标准区间、哪些是工程取值、哪些未验证。

## 12. 非目标

- 不做通用 CAD 建模器；
- 不做照片级三维重建；
- 不做自动盲文翻译服务；
- 不做在线商城或云端账户系统；
- 不替代特教老师做教学判断；
- 不宣称未经实体打印和盲人用户测试的“完全合规”。

## 13. 当前成熟度

- 75+ 项单元测试覆盖几何、布局、标准、路由、模型接入、文档读取、服务端；
- 8 个场景模板全部通过网格水密与合规检查；
- 函数、机械臂、三维、场景四条构建链路可端到端产出；
- 尚未完成：实体打印验证、盲人用户测试、正式录音、批量教材评测、汉语盲文转写。
