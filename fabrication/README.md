# 盲测材料制作包

这份文档对应 [`docs/blind_test_protocol.md`](../docs/blind_test_protocol.md) 第 4 节的四种材料。仓库本身不能直接变出实体板：A5 是 STL，需要 FDM 3D 打印机；A6 是 PDF，需要纸张打印；二维码要等音频页面有公开链接后再生成。

先打一块，检查没问题再批量打。不要把六块板一次性交给打印机。

## 1. A5 触觉板

### 1.1 打印机要求

- 成型尺寸至少 **220 × 220 mm**。A5 长边 210 mm，220 机器只剩 10 mm 余量，裙边要控制在 2–3 mm；**235 × 235 mm 或更大更稳**。
- 0.4 mm 喷嘴，PLA。不要用 0.2 mm 喷嘴，盲文点太细，打印时间也会翻倍。
- 建议白色或浅灰哑光 PLA。浅色对低视力用户更友好，哑光不反光；不要用丝绸、金属光泽或半透明材料。
- 不需要支撑，所有浮雕朝上。板子平放，不要竖着打。

如果只有 180 × 180 mm 的小机器，A5 放不下。不要缩放模型来硬塞：一旦缩放，1.0 mm 线宽、1.5 mm 盲文点和 6 mm 字高都会一起变小，触觉规格就失效了。换机器或送外协。

### 1.2 切片参数

以下是起点，不是经过实体打印验证的结论。不同机器需要微调。

| 参数 | 建议值 |
|---|---|
| 层高 | 0.2 mm |
| 首层 | 0.2 mm |
| 墙数 | 3 |
| 顶层 / 底层 | 4 / 4 |
| 填充 | 15–20%，网格或 gyroid |
| 支撑 | 关闭 |
| 打印方向 | 平板朝下，浮雕朝上 |
| 喷嘴温度 | 205–215 °C（按耗材） |
| 热床 | 60 °C，纹理 PEI 或干净玻璃 |
| 外墙速度 | 30–40 mm/s |
| 填充速度 | 80–100 mm/s |
| 接缝位置 | 后侧或对齐到板边，不要落在盲文点上 |
| 大象脚补偿 | 0.15–0.2 mm |
| 熨烫 | 关闭，尤其不要熨盲文和浮雕 |
| 裙边 | 需要时 2–3 mm；热床附着好可以不加 |

建议打开“避免跨越外墙”和“薄壁检测”。如果第一层局部不粘，先清洁热床、调平，再考虑加 3 mm 裙边；不要用大量胶水，胶水残留会污染二维码预留区。

### 1.3 先打一块检查

先各打 1 块，检查以下项目，再补打剩下的 2 块：

1. 尺寸用卡尺量，应为约 **148 × 210 × 3.8 mm**；不要只看切片软件里的数字。
2. 板子放桌上不翘边，四角不卷。
3. 指腹沿每条线滑动，不应有断点、毛刺或明显接缝。
4. 盲文点圆润、不拉丝，点与点不粘连；数字标签的点高应能摸出来。
5. 左上角 5 × 5 mm 缺口清楚；右下角 30 × 30 mm 二维码区平整，没有凸起或凹坑。
6. 腕部放大板里的三个小圆点能分别摸到，不糊成一条。

不要用砂纸打磨盲文点。拉丝用镊子轻轻夹掉；边缘毛刺可以用刀背轻刮，但不要碰浮雕顶面。

### 1.4 送打印店时直接发这段

```text
3D 打印需求：
- 文件：model.stl（两个案例各一个）
- 材料：PLA，白色或浅灰哑光
- 尺寸：148 × 210 × 3.8 mm，不缩放
- 喷嘴 0.4 mm，层高 0.2 mm，3 圈墙，15–20% 填充
- 不加支撑，平板朝下，浮雕朝上
- 接缝放后侧，不要落在盲文点上
- 先各打 1 件样品；确认无翘边、无拉丝、盲文点不粘连后，再各补 2 件
- 请拍首件照片，重点拍左上角缺口、盲文点和右下角空白区
```

### 1.5 时间和材料

- 单块约 3–6 小时，取决于机器和速度；六块不要指望一个晚上打完。
- 单块约 60–90 g PLA，取决于顶层/底层数和填充。两块材料成本通常不高，外协主要贵在开机费和工时。
- 如果学校工训中心、创客空间或学院实验室有打印机，优先用自己熟悉的机器；第一次打印建议在旁边看着首层。

## 2. A6 图例卡

### 2.1 打印规格

- 纸张：**A6，105 × 148 mm，250–300 g 白卡**。
- 单面打印，黑白即可；PDF 已经是白底黑字。
- 选择 **100% / 实际大小**，不要选“适合页面”或“缩放到 A4”。缩放会让中文和图例编号错位。
- 协议最低是一案一张；建议每个案例 2 张，多打 1 张备用。
- 如果过塑，用**哑光膜**；亮膜反光，低视力用户看起来更吃力。不过塑也可以，白卡更轻。

PDF 页面由浏览器导出，实测约 **105.16 × 148.17 mm**，比标准 A6 大约 0.16 mm。打印店按 A6 裁切即可；不要为了这 0.16 mm 把内容整体缩小，0.15% 的缩放没有意义，反而容易裁到边框。

### 2.2 裁切与使用

- 沿 A6 边缘裁切，保留图例四周的细边框。
- 图例卡不是触觉板，它的作用是让教师、家长或陪同者把编号映射到名称；盲人读者主要依靠板上的盲文编号和音频。
- 两张卡分别对应机械臂和函数图，不要混用。发放时让图例卡与板子的方向一致：缺口朝左上。

### 2.3 送打印店时直接发这段

```text
纸张打印需求：
- 文件：两个 A6 PDF
- 尺寸：A6，105 × 148 mm
- 纸张：250–300 g 白卡，单面
- 颜色：黑白
- 比例：100% 实际大小，不要缩放，不要拼版
- 每个文件先印 2 张，按 A6 裁切
- 如果过塑，请用哑光膜
```

## 3. 音频与二维码

### 3.1 试运行音频已经生成

`fabrication/audio/` 里有两个 WAV：

| 文件 | 时长 | 说明 |
|---|---:|---|
| `robot-arm-6axis.wav` | 约 1 分 24 秒 | Windows 中文语音合成，试运行版 |
| `quadratic-y-x2-2x-3.wav` | 约 1 分 13 秒 | 同上 |

这是 **TTS 试运行版**，不是最终真人录音。它的用途是先把扫码、外放、讲解顺序跑通；正式测试前应替换为真人朗读，并做三台手机播放测试。音频文字稿在对应的 `dist/<case>/audio.txt`。

本机试听：

```bash
cd "D:/11.7 AI Agent智能体大赛/touchlearn-fudan-Team_Stella"
python -m http.server 8000 --bind 0.0.0.0 --directory fabrication/audio
```

然后在电脑上打开 `http://127.0.0.1:8000/`，手机连同一个 Wi-Fi，打开 `http://<电脑局域网 IPv4>:8000/`。Windows 第一次可能会弹防火墙提示，选择“允许专用网络”。

这个局域网地址只适合试运行。不要在正式测试的贴纸上印 `192.168.x.x`：换个网络或路由器重启，二维码就失效了。试听结束后按 `Ctrl+C` 关闭服务，不要让它在公共网络上一直开着。

### 3.2 正式音频放哪里

二维码必须指向一个**手机能直接打开、无需登录、不会过期**的页面。推荐顺序：

1. **飞书/Lark 文档或云盘**：上传 WAV，建立一个包含音频播放器和文字稿的页面，分享设置为“互联网上获得链接的人可阅读”。这是国内手机最稳的方案。
2. **GitHub Pages**：把 `fabrication/audio/` 发布为静态页面。需要先在仓库 Settings → Pages 里启用；国内网络访问可能不稳定，正式测试前要用不挂代理的手机实测。
3. **学校/学院提供的静态空间**：如果实验室有公网目录，也可以。

不管用哪种方式，页面里要同时有音频和文字稿。不要只丢一个 MP3 链接：听障读者、无法外放的场景和音频加载失败时都需要文字稿。

正式音频替换后，保持文件名不变，音频页面就不用改；如果改了文件名，记得同步修改对应的 HTML。

### 3.3 生成二维码

拿到最终 URL 后，在本机执行：

```bash
python scripts/make_qr.py \
  --url "https://你的音频页面地址" \
  --out "fabrication/qr/robot-arm-6axis.png"
```

函数图同理：

```bash
python scripts/make_qr.py \
  --url "https://你的函数图音频页面地址" \
  --out "fabrication/qr/quadratic-y-x2-2x-3.png"
```

脚本会同时生成 PNG 和 SVG。需要 `qrcode[pil]`：

```bash
python -m pip install "qrcode[pil]"
```

二维码打印与粘贴：

- 打印在**防水哑光贴纸**上，尺寸控制在 **28 × 28 mm**，居中贴进右下角 30 × 30 mm 预留区；不要盖住虚线边框和相邻盲文。
- 二维码自带的白色静区（quiet zone）不能裁掉。`make_qr.py` 默认保留 2 个模块的边框，打印时不要把白边切掉。
- URL 越短越好。长 URL 会让二维码模块变密，28 mm 内可能不好扫；能用短链就用短链。
- 贴之前把板面擦干净、完全干燥；贴完用手压平，尤其是四角。
- 用三台不同手机、在正常室内光线下、距离 20–30 cm 各扫一次；不要只用自己的手机测试。
- URL 一旦变化，旧贴纸就报废，必须重新生成、重新打印。不要在一批贴纸上印临时地址。

### 3.4 二维码在板上的位置

两块板的右下角都预留了 30 × 30 mm 的平整区，位置是 **113–143 × 175–205 mm**，虚线边框内缩到 **114–142 × 176–204 mm**。二维码不是 STL 的一部分，打印完再贴。

贴纸方向要跟板子一致：缺口在左上，二维码在右下；不要把二维码贴倒。

## 4. 组装与测试前检查

### 4.1 数量

| 材料 | 正式测试建议数量 |
|---|---:|
| A5 机械臂板 | 3 |
| A5 函数板 | 3 |
| A6 机械臂图例 | 2（1 张使用，1 张备用） |
| A6 函数图例 | 2（1 张使用，1 张备用） |
| 机械臂二维码贴纸 | 4（3 块板各 1 张，多备 1 张） |
| 函数图二维码贴纸 | 4（同上） |

先打 1 块机械臂板 + 1 块函数板做试运行；试运行通过后再补到 3 块。试运行至少找 1–2 名视力正常但蒙眼的同事，不计入正式样本。

### 4.2 检查清单

- [ ] 每块板尺寸约 148 × 210 × 3.8 mm，不翘边。
- [ ] 左上角缺口清楚，四角倒角无锐边。
- [ ] 盲文点不粘连，数字标签能摸出点高。
- [ ] 右下角 30 × 30 mm 区域平整，贴纸不侵入浮雕。
- [ ] A6 图例按 100% 打印，裁切后是 105 × 148 mm。
- [ ] 两个音频页面在未登录的手机上能打开、能播放。
- [ ] 二维码在三台手机上都能扫开，页面加载不超过 5 秒。
- [ ] 贴纸贴正，缺口朝左上时二维码在右下。
- [ ] 湿巾、垫布、计时器、记录表、同意书、眼罩（试运行）齐备。
- [ ] 测试前用湿巾擦拭板面，不用刺激性清洁剂；干燥后再贴二维码。

### 4.3 已知边界

- 这些 STL **还没有经过实体打印验证**。首件必须检查翘边、拉丝、盲文点粘连和二维码区平整度。
- 当前音频是 **TTS 试运行版**，没有经过真人听测和三台手机播放测试。
- 二维码**还没有生成**，因为还没有确定公开音频 URL。`scripts/make_qr.py` 已可用，但不会伪造链接。
- 图例卡是 A6 打印件，不是独立触觉板；盲文索引已经在 A5 板上。
- 盲测结果不能拿试运行数据冒充正式样本。正式测试结束后，按 `docs/blind_test_protocol.md` 第 10 节把结果补回文档。

## 5. 建议顺序

1. 先各打 1 块 A5，检查首件。
2. 首件合格后，补打各 2 块；同时打印 A6 图例。
3. 用本地 HTTP 服务试听 TTS，确认讲解顺序和时长。
4. 换真人录音，上传到飞书/Lark 或 GitHub Pages。
5. 生成两个二维码，打印贴纸，贴到预留区。
6. 找 1–2 名蒙眼同事做试运行，修流程。
7. 再招募正式参与者，按盲测方案执行。

如果时间只够做一件事：先把首件打出来。STL 的几何检查替代不了真实打印；盲文点是否粘连、二维码区是否平整，只有摸到实物才知道。
