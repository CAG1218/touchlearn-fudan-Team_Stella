# Fix Report - 技术路线图被编译成一排无意义圆点

## Bug 描述

上传一张四列中文技术路线图（`技术路线图.jpg`）后，系统生成的触觉板出现：

- 标题变成 `BIONIC FLIGHT ROADMAP`，正文只剩 `CLEAR TOUCH GRID LAYOUT`、`STRUCTURE ONLY - TEXT PLACEHOLDERS` 一类的占位文字；
- 四个阶段的图标被压成 12 个无法区分的图块，板面上是一排方向不明的小圆点；
- 原始中文阶段名和要点全部丢失，用户无法通过触摸或旁白判断每一行代表什么。

这不是单一排版参数问题，而是“视觉模型把信息图当成图标拼贴”与“编译器只认识 ASCII 标签”两个缺陷叠加。

## 问题根因

1. **视觉模型返回占位描述**：对信息密度高的中文信息图，模型没有逐字转录，而是输出 `CLEAR TOUCH GRID LAYOUT / STRUCTURE ONLY - TEXT PLACEHOLDERS`，把“待填文字”当成了图形内容。
2. **编译器缺少占位符拦截**：`scene.generate_scene` 原先只检查结构是否合法，不检查语义是否是占位符，于是把占位文字忠实地压成了触觉板。
3. **场景标签只允许 ASCII**：`scene.py` 的 `ALLOWED` 字符集只含大写字母、数字和少量符号，中文标签在归一化阶段被丢弃，板上因此没有任何可读中文。
4. **信息图没有语义类型**：四列“阶段—要点”本质上是文字层级，不是空间图。按普通图块编译会把每个图标当成独立部件，用坐标还原视觉位置，文字层级反而丢失。
5. **中文盲文未接入触觉生成**：此前只支持 UEB（拉丁盲文），中文要么被跳过，要么整段消失，用户只能摸到抽象几何。
6. **选纸按“最宽一行”判断**：只要一行超宽不到 1 mm 就直接升到 A3，导致 A3 板上出现大片空白，内容集中在左侧。
7. **换行后的续行重复画圆点**：一条要点折成两行时，两行都画项目符号，视觉上像多出一条要点。

## 尝试记录

### 尝试 1：只改提示词，要求模型“更仔细地转录”

- 结果：失败。
- 原因：占位符是模型的退化输出，提示词无法保证它一定逐字转录；即使这次成功，下一次仍可能复现。必须在确定性层拦截。

### 尝试 2：继续用普通 scene 图块，把 12 个图块排成网格

- 结果：失败。
- 原因：网格布局保留的是图标位置，不是文字顺序。中文标签丢失后，图块之间没有可区分的语义，仍然是一排点。

### 尝试 3：新增 roadmap 语义类型，用确定性几何排“阶段—要点”

- 结果：成功。
- 做法：`normalize_roadmap` 接收 `stages[{heading, items}]`，按 A5→A4→A3 选择能放下全部行且点距不小于 8.6 mm 的最小纸张；左侧一条竖脊，阶段节点用大圆点，标题和要点用中文盲文逐行排布。
- 效果：4 个阶段、12 条要点完整保留，A4 板面点距约 9.4 mm，打印检查 PASS。

### 尝试 4：中文盲文直接编码

- 结果：部分失败后修复。
- 原因：拼音表把 `ü` 存成 ASCII `v`（如 `lv4`），而盲文韵母表用真正的 `ü` 作键，`率` 等字抛 `BrailleError` 后被静默丢弃，出现“机翼扑动频测试”。
- 修复：`cnbraille._canonical_final` 在查表前把 `v` 开头韵母还原为 `ü`，并处理 `j/q/x` 后的 `u`。

### 尝试 5：按行数而不是按最宽一行选纸

- 结果：成功。
- 原因：A4 上一条 9 字要点只超出不到 1 mm，折成两行即可容纳；按行数判断后稳定落在 A4，避免无意义的 A3 和大片空白。

## 最终方案

- `src/touchlearn/agent/scene.py`
  - 新增 `_PLACEHOLDER_RE` / `placeholder_marker()`，模型返回占位描述时直接拒绝生成，并提示用户改用文字描述或更清晰的图片。
  - 新增 `normalize_roadmap()` 与 `_roadmap_geometry()`：阶段标题、要点分别计算可用宽度，超宽时均衡折行；按 `A5 → A4 → A3` 的行容量选纸；行数超限时从末尾删减要点而不是缩小点距。
  - 路线图块使用竖脊、阶段节点、首行项目符号，续行不再重复画点；所有 x 坐标按纸张宽度偏移，A4/A3 不再挤在左侧。
  - 视觉提示词与离线模板增加 roadmap 分支，明确“文字为主的图优先提取阶段和要点，不要描摹图标”。
- `src/touchlearn/cnbraille.py`
  - 修复 `ü` 韵母规范化，中文盲文覆盖拼音表中的全部 GB2312 汉字。
- `src/touchlearn/agent/agent.py`
  - 显式 `roadmap` 字段可直接进入路线图编译器；选纸优先使用 scene 的 `paper_hint`。
- `src/touchlearn/agent/parametric.py`
  - 修复页脚文字贴边导致的 `edge_margin` 打印检查失败（这是既有缺陷，路线图重建时暴露）。

## 经验教训

1. **模型输出必须当作不可信输入**：结构合法不等于语义有效，占位符、空标签、重复标签都要在确定性层拦截。
2. **信息图先判语义类型**：技术路线图、时间轴、组织结构图是文字层级，不是空间图；先转成“阶段—要点”，再交给几何内核。
3. **中文支持要端到端验证**：编码、宽度、包围盒、STL、SVG、打印检查任一环丢字，最终板面都会缺内容。用真实长文本做端到端用例，比只测单字更可靠。
4. **选纸应由可读性决定**：先保证点距和行数，再选最小纸张；按单行宽度直接升级会制造大片空白。
